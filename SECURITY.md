# Security Policy

## Supported Versions

Currently, only the latest release of Git Resolve is supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within Git Resolve, please do not disclose it publicly. 

Instead, report it directly to the core team by joining our community Discord channel:

**[StarBorn Community Discord](https://discord.com/invite/4DNhRb87my)**

Please provide a detailed description of the issue, the steps to reproduce it, and any potential impact. We take all security reports seriously and will work with you to verify and resolve the issue as quickly as possible.
